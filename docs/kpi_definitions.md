# KPI definitions

| KPI | Definition | Notes |
|---|---|---|
| Approval rate | Approved / (Approved + Denied + Partially Approved) | Pending excluded; denominator includes partial decisions |
| Denial rate | Denied / (Approved + Denied + Partially Approved) | Pending excluded |
| Pending claims | Count of Pending status | Operational backlog indicator, not an approval outcome |
| Average processing days | Mean processing_days where available | Pending rows may have no value |
| Submitted claim amount | Sum of claim_amount | Not paid amount, reimbursement or liability |
| Denial reason count | Count of denied claims by denial_reason | Descriptive categorization only |

This is a learning dataset. Metrics must not be used for medical, insurance, regulatory or financial decisions.
